# Смены — календарь рабочих смен (SwiftUI, iOS 16+)

Нативное приложение для iPhone: циклический график смен, несколько шаблонов,
ручные правки дней и часов, деньги за месяц, экспорт и напоминания. Всё хранится
локально в JSON, никаких серверов и аккаунтов.

## Что нового в версии 2.0

- **Календарь на весь экран** — сетка растягивается по высоте, без внутренней прокрутки.
- **Редактирование смен и часов** — тап по дню: выбрать другой тип смены, отметить
  выходной, поправить фактические часы (±0,5) и вернуть «по циклу».
- **Деньги** — ставка за час или за смену, надбавка за ночные, оплата переработки,
  итог за месяц и по каждому типу смены.
- **Несколько графиков** — храни 2/2 на зиму и 3/3 на лето, переключайся одним тапом.
  Ручные правки дней при этом сохраняются.
- **Обзор года** — 12 месяцев с точками смен и количеством рабочих дней.
- **Свайп по месяцам** — влево/вправо по календарю.
- **Экспорт** — `.ics` для «Календаря» iPhone и PDF на месяц.
- **Бэкап JSON** — выгрузка и загрузка всех данных через AirDrop / «Файлы».

## Что умеет

- **Графики (шаблоны)** любой длины: 2/2, 3/3, 4/2, 1/3, своя последовательность.
  У каждого графика своё имя, дата-якорь и цикл типов смен.
- **Календарь на месяц**: цветные метки смен, «сегодня», точки ручных правок и
  заметок, часы в ячейке, итоговая строка месяца (смены · часы · деньги).
- **Типы смен**: название, короткое обозначение, цвет, начало/конец, ставка и
  ночная надбавка. Ночные (конец раньше начала) считаются через полночь.
- **Оплата**: за час или за смену; ночные часы — пересечение смены с окном
  (по умолчанию 22:00–06:00); переработка — часы сверх длительности смены.
  Валюта, множитель переработки и ночное окно настраиваются.
- **Статистика за месяц**: смены, часы, ночные, переработка, начислено, разбивка
  по типам и текущие тарифы.
- **Напоминания** о смене в выбранное время (локальные уведомления).
- Русский интерфейс, светлая и тёмная тема, только iPhone, только портрет.

## Как получить .ipa без Mac (GitHub Actions)

Сборка идёт на macOS-раннере GitHub, результат — **unsigned .ipa**, который
подписывается твоим сертификатом в eSign.

1. Создай репозиторий на github.com (можно приватный), без README.
2. На странице репозитория: **Add file → Upload files**, перетащи туда **всё
   содержимое папки `shift-calendar`** (включая папки `.github` и `ShiftCalendar`).
   Commit.
   - Если папка `.github` не загрузилась: **Add file → Create new file**, имя
     `.github/workflows/build-ipa.yml`, и вставь содержимое одноимённого файла
     из проекта.
3. Вкладка **Actions** → если GitHub спросит, нажми
   *«I understand my workflows, go ahead and enable them»*.
4. Слева выбери **Build unsigned IPA** → **Run workflow** → **Run workflow**
   (или просто дождись автозапуска после коммита).
5. Через ~3–5 минут открой завершённый запуск, внизу раздел **Artifacts** →
   скачай `ShiftCalendar-unsigned-ipa.zip`.
6. Распакуй архив — внутри `ShiftCalendar-unsigned.ipa`.

## Как подписать в eSign

1. Открой eSign → **Import** / «+» → выбери `ShiftCalendar-unsigned.ipa`.
2. Укажи свой `.p12` + пароль и `.mobileprovision` (или готовый сертификат из
   хранилища eSign).
3. **Sign** → **Install**.

Важно:

- Если сертификат выпущен под конкретный Bundle ID, поменяй его в `project.yml`:
  `PRODUCT_BUNDLE_IDENTIFIER: com.example.shiftcalendar` → свой, затем пересобери.
- Для development-сертификата UDID iPhone должен быть в профиле.
- Подпись с бесплатным Apple ID живёт 7 дней, с платным — год. Переподписать можно
  тем же файлом `.ipa`, пересобирать не нужно.

## Обновление с версии 1.0

Ставь новый `.ipa` **поверх** старого, не удаляя приложение, и с тем же Bundle ID.
Файл данных мигрирует автоматически: старый цикл станет графиком «Основной»,
заметки и правки дней сохранятся. Версия схемы поднимается с 1 до 2.

Перед обновлением можно сделать бэкап: **Настройки → Экспорт и бэкап →
Резервная копия (.json)**.

## Сборка на Mac (если появится)

```bash
brew install xcodegen
xcodegen generate
open ShiftCalendar.xcodeproj
```

Дальше обычный Run на устройство (нужен свой Team в Signing & Capabilities).

## Где что менять

| Что | Где |
|---|---|
| Название приложения на экране | `project.yml` → `CFBundleDisplayName` |
| Bundle ID | `project.yml` → `PRODUCT_BUNDLE_IDENTIFIER` |
| Версия | `project.yml` → `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` |
| Дефолтный график и ставки | `ScheduleData.makeDefault()` |
| Валюта, переработка, ночное окно | `AppSettings` (меняются в приложении) |
| Палитра цветов для смен | `Support/Color+Hex.swift` → `Palette.hexes` |
| Горизонт напоминаний (30 дней) | `ReminderScheduler.schedule` |

## Ограничения

- **Виджет и iCloud-синхронизация не включены.** Они требуют App Groups / CloudKit
  entitlements из Apple Developer Portal, которые не подхватываются при подписи
  через eSign (приложение было бы установлено, но виджет остался бы пустым, а синк
  молча не работал). Вместо них — экспорт/импорт JSON: перенос между устройствами
  через AirDrop или iCloud Drive.
- Учёт только по факту: бухгалтерские коэффициенты, налоги и премии не считаются.
- Apple Watch нет.
